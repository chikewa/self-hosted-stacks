# Chikewa — Self-Hosted Docker Stacks

Production-tested Docker Compose stacks and home-server guides from [https://chikewa.com](https://chikewa.com).

Every stack has its **own public repo**: the full tested guide as a README, the ready-to-run `docker-compose.yml`, and every config file the guide uses. Clone a repo, tweak the hostnames/ports, `docker compose up -d`, done.

**21 stacks** · all tested on a Debian 12 mini PC with Docker
